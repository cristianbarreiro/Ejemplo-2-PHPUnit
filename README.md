## 🧪 PHPUnit - Proyecto de Pruebas

Este repositorio contiene un ejemplo de proyecto PHP con tests automatizados usando PHPUnit.

El propósito es demostrar cómo se pueden escribir y correr pruebas unitarias para una clase simple, como FizzBuzz.


## Clonar repositorio

git clone https://github.com/cristianbarreiro/nombre-repo.git
git checkout (rama)


## Instalar PHPUnit con composer

composer require phpunit/phpunit --dev


## Correr autoload

composer dump-autoload

(Configurar correctamente composer.json)


## Correr tests

./vendor/bin/phpunit tests
